# Weather App

## Description
This project is a Weather App that fetches real-time weather data using OpenWeather API.

## Features
- Search weather by city
- Displays temperature and condition
- Uses live API data

## Tech Stack
- HTML
- JavaScript
- API (OpenWeather)
